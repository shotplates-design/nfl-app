# Game conditions feeds
The live drop-in file is `data/week-N-conditions.json` (this week: `data/week-6-conditions.json`). Replace that file before a kickoff window and redeploy. Shape: `{week, updated, games:[{away, home, kickoff_et, weather:{indoor,temp_f,wind_mph,precip_pct,impact,note}, injuries:[{team, player, position, status, injury, source_url, note?, with_without?}], with_without?}]}` using team abbreviations (`WAS` is accepted for Washington). The loader reads `data/week-N-conditions.json` first and falls back to `data/feeds/week-N-conditions.json`.
