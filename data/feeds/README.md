# Game conditions feeds
The live drop-in file is `data/week-N-conditions.json` (this week: `data/week-6-conditions.json`). Replace that file before a kickoff window and redeploy. Shape: `{week, updated, games:[{away, home, weather, injuries, with_without, kickoff_et?, inactives?, inactives_note?}]}`. Injuries may include `note` and `practice_latest` (shown on the matchup injury list). `inactives` may be absent; the page still renders the note. Team abbreviations: `WAS` is accepted for Washington. The loader reads `data/week-N-conditions.json` first and falls back to `data/feeds/week-N-conditions.json`.
